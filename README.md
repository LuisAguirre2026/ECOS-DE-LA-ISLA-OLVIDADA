# ECOS-DE-LA-ISLA-OLVIDADA
Isla Aventura es un videojuego infantil de exploración y puzles diseñado para niños de 8 a 12 años.El juego se desarrolla en una isla mágica que perdió su energía debido a una tormenta. El objetivo principal es recorrer y "reparar" la isla resolviendo diversos desafíos a través de un avatar personalizado
