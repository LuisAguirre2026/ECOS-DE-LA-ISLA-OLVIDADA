# ECOS-DE-LA-ISLA-OLVIDADA
Es un videojuego infantil de exploración y puzles diseñado para niños de 8 a 12 años.El juego se desarrolla en una isla mágica que perdió su energía debido a una tormenta. El objetivo principal es recorrer y "reparar" la isla resolviendo diversos desafíos a través de un avatar personalizado
# FASE 1 / Análisis del videojuego
Descripción de lo que trata el videojuego, además de sus características principales para el desarrollo del diagrama de flujo.
# FASE 2 / Diagrama de flujo
En el diagrama de flujo se muestra cómo el jugador crea su personaje, explora los biomas, completa retos, obtiene recompensas y avanza en el juego. Si necesita ayuda, Nix le da pistas. Al completar todos los biomas, termina el juego.
